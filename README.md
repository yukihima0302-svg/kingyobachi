# すむら呉服店 ウェブサイト

Jekyll で組んだ、GitHub Pages で公開するためのサイト一式です。
記事は Markdown で書けます。

---

## 1. 最初に書き換えるところ

**`_config.yml`** を開いて、上半分だけ直してください。ここを直すと、全ページの表示が
いっせいに変わります。同じことを何ページにも書く必要はありません。

| 項目 | 中身 |
|---|---|
| `title` | 店の名前（仮に「すむら呉服店」と入れてあります） |
| `latin_name` | 見出しに小さく入る欧文表記 |
| `tagline` | 一行のキャッチコピー |
| `shop:` 以下 | 住所・電話・営業時間・定休日・アクセス |
| `shop.map_query` | 地図に出す住所。Googleマップで検索して出る文字列を入れてください |

`〇〇` と `0000` になっているところが未記入の箇所です。

## 2. GitHub に置いて公開する

1. GitHub で新しいリポジトリを作る（公開範囲は **Public**）
2. このフォルダの中身を、フォルダごとではなく **中身をそのまま** アップロードする
   （`_config.yml` がリポジトリの一番上に来るように）
3. リポジトリの **Settings → Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 一〜二分待つと、Pages の画面に公開URLが出ます

### baseurl のこと

- `ユーザー名.github.io` という名前のリポジトリにした場合 → `_config.yml` の
  `baseurl:` は空のままで大丈夫です
- それ以外の名前（例：`kimono`）にした場合 → `baseurl: "/kimono"` と書き足してください

ここを間違えると、見た目だけが崩れて文字だけのページになります。崩れたらまずここを疑ってください。

## 3. 記事を書く

`_posts` フォルダに、次の名前でファイルを足すだけです。

```
2026-08-15-natsu-no-shimatsu.md
```

**日付から始めるのが決まりです。** 名前の後半は英数字なら何でもかまいません。

ファイルの中身はこう書きます。

```markdown
---
title: "夏物のしまい方"
date: 2026-08-15
category: 手入れのこと
---

ここから本文です。空行で段落が分かれます。

## 中見出しはシャープ二つ

- 箇条書きはハイフン
- こう書きます

写真は ![説明](/assets/img/shashin.jpg) と書けば入ります。
```

上の `---` で挟まれた部分は設定、その下が本文です。`category` は好きな言葉で結構です。

書き終えたら GitHub にアップロードすれば、一〜二分で公開されます。

## 4. 反物を追加する

`_data/gallery.yml` に、かたまりを一つ足すだけです。

```yaml
- name: "浅葱地 麻の葉"
  kind: "紬"
  note: "一行の説明。長くても二行まで。"
  price: "98,000円"
  image: "asagi-asanoha.jpg"
  pattern: "asanoha"
  tone: "asagi"
```

- `image` に写真のファイル名を書くと、その写真が出ます
- `image: ""` と空にすると、代わりに `pattern` の文様が織り柄として描かれます
  （写真がまだ撮れていないときに）
- `pattern` に使えるもの … `yagasuri` 矢絣 / `kikko` 亀甲 / `seigaiha` 青海波 /
  `asanoha` 麻の葉 / `ichimatsu` 市松
- `tone` に使えるもの … `fuji` 藤 / `asagi` 浅葱 / `kobai` 紅梅 / `kogane` 古金
- `price` を `""` と空にすると「お問い合わせください」と出ます

写真は `assets/img/` に入れてください。

## 5. 手元で確かめたいとき（任意）

やらなくても公開はできます。やる場合は Ruby を入れたうえで、

```bash
bundle install
bundle exec jekyll serve
```

`http://localhost:4000` で見られます。

```

index.html           トップページ
gallery.html         反物一覧
blog.html            記事一覧
info.md              店舗情報
```

## 意匠について

大正末から昭和初期の **銘仙** ——
アール・デコの幾何学がそのまま織り柄になった、あの時代の布を下敷きにしています。

- 色は染めの名前から：白藤の地、濃藍の墨、藤紫と錆浅葱、紅梅、罫の古金
- 書体は明朝（しっぽり明朝）を主に、欧文だけデコ体の Poiret One
- 版面を金の二重罫で囲い、四隅に段違いの角飾りを置いています
- 地紋にごく薄い矢絣

いちばんの仕掛けは **反物棚** です。巻かれた反物が横に並んでいて、
触れるとその一反だけがほどけて中の柄が見える。
きものは巻いた状態で売られる、という商いのかたちをそのまま操作にしました。
