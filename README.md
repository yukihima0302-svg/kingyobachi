# 金魚鉢 ウェブサイト

Jekyll で組んだ、GitHub Pages で公開するためのサイト一式です。
記事は Markdown で書けます。

---

## 1. 最初に書き換えるところ

**`_config.yml`** を開いて、上半分だけ直してください。ここを直すと、全ページの表示が
いっせいに変わります。同じことを何ページにも書く必要はありません。

| 項目 | 中身 |
|---|---|
| `title` | 店の名前 |
| `latin_name` | 見出しに小さく入る欧文表記 |
| `tagline` | 一行のキャッチコピー |
| `shop:` 以下 | 住所・電話・営業時間・定休日・アクセス |
| `shop.map_query` | 地図に出す住所。Googleマップで検索して出る文字列を入れてください |

`〇〇` と `0000` になっているところが未記入の箇所です。

---

## 2. GitHub に置いて公開する

1. GitHub で新しいリポジトリを作る（公開範囲は **Public**）
2. このフォルダの中身を、フォルダごとではなく **中身をそのまま** アップロードする
   （`_config.yml` がリポジトリの一番上に来るように）
3. リポジトリの **Settings → Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 一〜二分待つと、Pages の画面に公開URLが出ます

### baseurl のこと

- `ユーザー名.github.io` という名前のリポジトリにした場合 → `_config.yml` の
  `baseurl:` は空のままで大丈夫です
- それ以外の名前（例：`kimono`）にした場合 → `baseurl: "/kimono"` と書き足してください

ここを間違えると、見た目だけが崩れて文字だけのページになります。崩れたらまずここを疑ってください。

## 3. 記事を書く

`_posts` フォルダに、次の名前でファイルを足すだけです。

```
2026-08-15-natsu-no-shimatsu.md
```

**日付から始めるのが決まりです。** 名前の後半は英数字なら何でもかまいません。

ファイルの中身はこう書きます。

```markdown
---
title: "夏物のしまい方"
date: 2026-08-15
category: 手入れのこと
---

ここから本文です。空行で段落が分かれます。

## 中見出しはシャープ二つ

- 箇条書きはハイフン
- こう書きます

写真は ![説明](/assets/img/shashin.jpg) と書けば入ります。
```

上の `---` で挟まれた部分は設定、その下が本文です。`category` は好きな言葉で結構です。

書き終えたら GitHub にアップロードすれば、一〜二分で公開されます。

## 4. きものを一枚追加する

`_kimono` フォルダに、ファイルを一つ足します。ファイル名がそのままURLになるので、
**英数字とハイフン**で付けてください（`asagi-komon.md` → `/kimono/asagi-komon/`）。

```yaml
---
shinamei: "浅葱地 麻の葉"      # 品名
kind: "紬"                     # 種別
era: "昭和初期"                # 時代（分からなければ ""）
shitake: "150"                 # 身丈（cm・数字だけ）
yuki: "63"                     # 裄
sodetake: ""                   # 袖丈（測ったときだけ）
midaba: ""                     # 前幅（測ったときだけ）
jotai: "衿元に薄いシミ。着用時は帯で隠れます"
price: "18,000円"              # "" にすると「お問い合わせください」
sold: false                    # 売れたら true に変える
images: []                     # 写真。下を参照
pattern: "asanoha"             # 写真がないときの柄
tone: "asagi"                  # その柄の色
kounyu_url: ""                 # BASE等の商品ページURL。あればボタンがそこへ飛ぶ
order: 7                       # 並び順。小さいほど先
---

ここに説明を書きます。一行でも、長くても構いません。
一覧には最初の46文字が出ます。
```

### 写真

`assets/img/` に入れて、ファイル名を並べます。**上から順に表示されます。**

```yaml
images: ["asagi-1.jpg", "asagi-2.jpg", "asagi-3.jpg"]
```

一枚目が一覧のサムネイルになります。長辺1600pxくらいに縮めておくと軽くなります。

### 売れたとき

`sold: false` を `sold: true` に変えるだけです。商品ページは残ったまま「売り切れ」
と表示され、一覧では「お嫁に行った一枚」の欄に移ります。**消さないでください。**
過去に何を扱ってきたかは、店の信用そのものです。

### 柄と色（写真がないとき）

- `pattern` … `yagasuri` 矢絣 / `kikko` 亀甲 / `seigaiha` 青海波 / `asanoha` 麻の葉 / `ichimatsu` 市松
- `tone` … `fuji` 藤 / `asagi` 浅葱 / `kobai` 紅梅 / `kogane` 古金

## 注文の受け取りかた

`_config.yml` の `shop_url` が空のあいだは、商品ページの「注文する」ボタンを押すと
**注文用の紙**が開きます。お客さんが名前と連絡先を書くと文面が組み上がり、
コピー・メール・電話のいずれかでこちらに届きます。決済は入っていません。
届いた注文に返信して、振込先をお伝えする流れです。

BASE や minne などに出品する場合は、各きものの `kounyu_url` にその商品ページの
URLを入れてください。ボタンがそちらへ飛ぶようになります。
`_config.yml` の `shop_name` に店の名前（例: `BASE`）を書くと、ボタンの文字が
「BASEで買う」に変わります。

## 5. 手元で確かめたいとき（任意）

やらなくても公開はできます。やる場合は Ruby を入れたうえで、

```bash
bundle install
bundle exec jekyll serve
```

`http://localhost:4000` で見られます。

## 意匠について

大正末から昭和初期の **銘仙** ——
アール・デコの幾何学がそのまま織り柄になった、あの時代の布を下敷きにしています。

- 色は染めの名前から：白藤の地、濃藍の墨、藤紫と錆浅葱、紅梅、罫の古金
- 書体は明朝（しっぽり明朝）を主に、欧文だけデコ体の Poiret One
- 版面を金の二重罫で囲い、四隅に段違いの角飾りを置いています
- 地紋にごく薄い矢絣

いちばんの仕掛けは **反物棚** です。巻かれた反物が横に並んでいて、
触れるとその一反だけがほどけて中の柄が見える。
きものは巻いた状態で売られる、という商いのかたちをそのまま操作にしました。
